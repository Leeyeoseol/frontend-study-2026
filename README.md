### 📝 Issue 규칙

#### 제목

```text
[1주차] 11/12(목) 시작
```

#### 내용

```md
## 목표

- [ ]

## 완료 기준

- [ ]

## 메모

-
```

학습을 시작하기 전에 Issue를 생성하고, 학습이 끝나면 완료 여부를 확인한 뒤 Close합니다.

---

### 📌 Commit 규칙

| 타입       | 설명                              |
| ---------- | --------------------------------- |
| `feat`     | 기능 구현 및 실습                 |
| `fix`      | 오류 수정                         |
| `docs`     | README 등 문서 수정               |
| `style`    | 코드 스타일 변경 (동작 변경 없음) |
| `refactor` | 코드 리팩토링                     |
| `chore`    | 기타 작업                         |

### 🚀 Git 사용 방법

#### 최초 한 번만

```bash
git init
git remote add origin <저장소 주소>
```

#### 학습 후 Push

```bash
git add .
git commit -m "커밋 메시지"
git push origin main
```

#### 변경 사항 확인

```bash
git status
```

#### 원격 저장소 확인

```bash
git remote -v
```

#### 최신 코드 가져오기

```bash
git pull origin main
```

### 📖 학습 원칙

- 하루 학습을 시작하기 전에 Issue를 작성한다.
- 기능 또는 학습 단위로 Commit한다.
- 학습이 끝나면 GitHub에 Push한다.
- 완료한 Issue는 Close한다.
- 폴더는 날짜가 아닌 **학습 주제별**로 관리한다.
